# Basic Chatbot 

A simple rule-based chatbot built in Python as part of
the CodeAlpha Python Programming Internship.

##  About
CodeBot responds to user messages using predefined rules.
It recognizes greetings, questions, jokes, time/date
queries and more — all using if-elif logic.

## Key Concepts Used
- if-elif — to match user input to predefined replies
- functions — get_response() handles all chatbot logic
- loops — while loop keeps the conversation going
- input/output — to interact with the user in terminal

##  Features
- Responds to greetings, farewells, and common questions
- Tells the current time and date
- Tells a joke on request
- Handles empty input gracefully
- Exits cleanly when user says 'bye'

##  How to Run
Make sure Python is installed, then run:
    python chatbot.py

##  Built With
- Python 3 (no external libraries needed)
